# Football Odds Scraper (Python + BeautifulSoup) — sample project

A scraper that reads BetExplorer's public football listing page and extracts
league, kick-off date/time, teams, **1X2 odds** for upcoming matches and final
scores for finished ones, exporting everything to a clean UTF-8 CSV.

The demo run collected **60 matches across 34 leagues** (10 upcoming fixtures
with full 1X2 odds, 50 finished matches with scores) into `odds.csv`.

## Highlights

- **Grouped-table parsing** — follows tournament header rows so every match is tagged with its league
- **Two row layouts handled** — upcoming-fixture rows and results rows
- **Date handling** — kick-off parsed from the row's data attribute
- **Polite crawling** — real browser User-Agent, delay between requests, timeouts, error handling
- **Structured CSV output** — date, kickoff, status, league, home_team, away_team, odd_1, odd_x, odd_2, score, match_url

## Run it

```bash
pip install requests beautifulsoup4
python odds_scraper.py --max-matches 60 --delay 2.0 --out odds.csv
```

This is a demonstration sample showing my scraping workflow end to end.
No client, no fake data — the CSV was generated by a real run on 2026-09-15.
